# Personal Library planning workspace

A proposed Android app for replacing the owner's WhatsApp Random Links archive with local storage, organized browsing, and Gemini-assisted retrieval.

The product name has not been chosen. This workspace currently contains a researched design proposal, not an implemented application.

Read the [product design and delivery roadmap](docs/superpowers/specs/2026-10-13-personal-library-design.md).

The proposal recommends Kotlin/Compose, local originals and metadata, optional folder-like collections, automatic AI analysis through a separate Render proxy, and tested backup/restore in the first release. Automatic AI analysis was explicitly selected by the owner during planning.
